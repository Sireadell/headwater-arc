Headwater on Arc

Headwater checks who paid for the reviews on Arc's AI agents. It then writes what it finds onto Arc itself, so you can check the check.

I built it because a rating is only worth something if the person giving it isn't the agent's own owner in disguise. It's the same trick as a seller who makes a second account to praise their own shop.

What this does not say

  • It is evidence, not an accusation. A link means one wallet sent money to another. It doesn't prove anyone cheated, and it doesn't read anyone's mind.
  • I only follow the first payment into a wallet, up to two steps back. A reviewer funded some other way won't show a link.
  • Wallets that made thousands of payments (exchanges, bridges, faucets) are ignored as funders, because being paid by one of them links you to nobody. 9 were set aside. If such a wallet is the agent's own owner, it still counts.
  • The wallet I used to write these records (0xb3FB...2B53) is mine. It left one review, on agent 192, and it was also the first wallet to send money to agent 192's owner (0.0012 USDC). So agent 192 is flagged. It is a link, and I am telling you.
  • I can't see owners who review each other's agents as a ring, or reviewers who review each other, when a busy wallet funded them all.
  • I scanned Arc from block 10,000,000 to block . Payments before that aren't in view.

How the record on Arc works

For each agent with a link I sent one small transaction from my wallet to itself, with no money moved. The note inside is text: the agent number, the reviewer wallets, and the transaction that funded each one. Open any record above, then open the funding transaction named inside it. You'll see the same payment. On the explorer, the note first shows as hex. Click "View details", then switch the data to UTF-8 to read it.

Reads Arc's ERC-8004 registries and the network's USDC payment log. No outside indexer. Source
