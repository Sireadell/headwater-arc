How we check it

Five things to know

  1. Arc keeps a public list of reviews for each AI agent. The list shows scores, not who paid the reviewers.
  2. We follow each reviewer’s money back two steps, using USDC payments on Arc. USDC is a coin that is worth one US dollar.
  3. If the agent’s own owner paid a reviewer, directly or through one other wallet, we say so and link the payment.
  4. A payment link is evidence, not an accusation. A paid campaign can be legitimate.
  5. With fewer than 3 reviewers the result is amber and says “Too few to judge.” We do not show percentages.

What we cannot see

    For developers and AI agents

    The same verdicts are published as data, so a program can check an agent before it pays one:

    • api/index.json: all agents with reviews
    • api/agents/<number>.json: one agent. A missing file means NO EVIDENCE.
    • api/rings.json: money sources behind more than one agent
    • mcp/server.mjs: the same answers through an MCP server

    Engineering detail (how USDC is counted, block windows, signal thresholds) is kept in the repository, not on this page.
